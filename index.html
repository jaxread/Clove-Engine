Clove Engine

Clustered Deferred
A lightweight custom game engine

About

Clove Engine is a custom 3D game engine built with Vulkan. It features a clustered-deferred rendering pipeline with tiled/clustered lighting and efficient shadowing, focused on performance and developer control.

Features

  • Vulkan rendering backend
  • Clustered-deferred rendering pipeline (tiled/clustered lighting)
  • Dynamic lighting and shadows
  • 3D game development tools
  • Custom asset and save formats
