Clove Engine

A custom game engine built from the ground up.

About

Clove is a personal game engine focused on performance, graphics, and giving developers full control over their games. Built with modern rendering technology and designed to grow over time.

Features

  • Custom rendering pipeline
  • 3D game support
  • Physics integration
  • Custom asset and save formats
  • Developer-focused tools
